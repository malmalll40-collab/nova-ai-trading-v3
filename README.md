- 차트 주기 일·주·월·연봉, 기존 시세 공급원 선택, 20초 KIS REST 장중 차트 갱신은 유지합니다. 15분 분석과 차트 실시간 봉 갱신은 서로 다릅니다.
- KIS_APP_KEY와 KIS_APP_SECRET 및 조회 권한이 필요합니다. KIS 실시간 WebSocket은 지원하지 않으며, 실전 15분봉의 완성도·시차와 슬리피지는 운영 시 검증이 필요합니다.

# NOVA AI Trading Mobile v4.4 — 종목추천 1차 선별 과거 백테스트

## 무엇을 추가했나요?

기존 v4.3 **종목추천** 화면의 아래쪽에 **종목추천 과거 1차 선별 백테스트** 영역을 추가했습니다.

- **과거 4주/8주 기준일**: 매주 한 번 과거의 전 종목 일별 스냅샷을 조회해 코스피·코스닥 전체 또는 단일 시장을 1차 선별합니다. 즉 매일 연속 전체 거래일을 검증하는 4주/8주가 아니라 **4개/8개 주간 기준일**입니다.
- 기존 v4.3 `market_scanner.screen()`을 **그대로 재사용**합니다. 가격, 거래대금, 시가총액, 등락률, 거래정지 여부로 선별하고 스코어 상위 **최대 8종목**을 사후 검증합니다.
- 금융위원회 일별 시세정보(`FSC_STOCK_API_KEY`)를 당시 시점의 *선별 데이터*로 사용합니다. 시세 전 페이지를 빠짐없이 받지 못하면 중단합니다.
- 사후 평가는 Yahoo Finance의 조정된 **일봉 시가·종가**로 진행합니다. 공급원 요청 제한이나 상장폐지 등으로 자료를 못 받으면 **검증 불가**로 표시하고 적중률에서 제외합니다. 누락 비중을 반드시 확인하세요.
- **자료 공개 시점**을 반영합니다: T일 일별 데이터는 T+1 영업일 오후 1시 이후 공개된다고 가정하여, 매매 시점은 **T+2 거래일 시가**로 지연시킵니다. T 종가나 T+1 시가에 진입한 것으로 계산하지 않습니다.
- 가상 보유 **1·3·5·10거래일** 뒤 종가에 청산합니다. 1거래일은 *매수 당일 종가*까지입니다. 매매 비용은 **편도 0~100bp** (기본 15bp), 왕복 두 차례 차감합니다. 슬리피지, 매수 불가, 거래량 영향은 별도 보정되지 않았습니다.
- 검증 건수, 적중률(순수익률 양수), 평균·중앙값 순수익률, 최악/최고 거래 결과, 시장별 5일 성과, 기준일별 기록을 표시합니다. 검증 결과는 Render 프로세스 메모리에서만 보관됩니다.

## 중요한 정의: 이것은 최종 NOVA 추천 백테스트가 아닙니다

현재 NOVA의 실제 최종 매수 후보에는 **기술적 안정형 신호, 독립 구간의 조건 검증, OpenDART 재무 위험 필터, 손익비**가 추가됩니다. v4.4의 과거 검증은 **전체 시장 일별 스냅샷을 사용한 1차 유동성·가격 선별 로직의 과거 결과만** 재현합니다. 그 이후의 최종 NOVA 필터를 과거에 적용했다고 주장하지 않습니다. 과거 각 시점의 재무공시 공개 여부/정정, 매매 가능성 등도 복원하지 않습니다. 예측 확률을 보정하지 않았습니다.

- v4.3과 동일한 최종 추천 규칙의 **완전한 적중률**은 이번 버전에 **없습니다**.
- 병렬 시점의 주간 매매가 겹칠 수 있어 **포트폴리오 누적수익률 및 MDD는 계산하지 않습니다**. 거래별 평균 수익률은 포트폴리오 투자수익률이 아닙니다.
- 종목이 상장폐지되거나 Yahoo에서 시세가 빠진 경우 **생존자 편향**이 있을 수 있습니다. 조정주가 사용에 따른 차이가 있을 수 있고, 실제 호가·슬리피지·체결 가능성이 반영되지 않았습니다.
- 4/8 주간 기준일은 작은 표본입니다. 특정 국면에서의 성과가 앞으로 반복된다는 보장이 없습니다.

## 설치 및 실제 실행

1. **v4.5 배포**: GitHub `malmalll40-collab/nova-ai-trading-v3`에서 이전 ZIP을 로컬 백업한 뒤 제거하고 `NOVA_v4_5_update.zip` **하나만** 업로드한 뒤 Commit합니다. 이 아래 절은 v4.4 백테스트의 동작 설명을 보존한 것입니다.
2. Render에서 배포가 `Live`인지 확인합니다. 기존 `FSC_STOCK_API_KEY`, `NOVA_ACCESS_TOKEN`, `OPENDART_API_KEY`는 수정할 필요 없습니다.
3. 앱 하단 **종목추천** 탭으로 들어갑니다. 시장은 전체/코스피/코스닥 중 선택합니다.
4. 아래 **종목추천 과거 1차 선별 백테스트**에서 4주 또는 8주를 선택합니다.
5. **과거 추천 후보 성과 검증** 버튼을 누릅니다. 과거 일별 전체 시장과 최대 8개 종목의 가격을 여러 번 조회하므로 진행에 시간이 걸릴 수 있습니다. 서버 중단·API 호출 제한·시세 부족 시 오류 또는 미확인으로 표시합니다.
6. 결과의 **완료 건수/전체 건수**를 먼저 확인합니다. 100% 미만이면 전체 적중률로 일반화하지 마세요.
7. 결과가 보이면 화면 캡처를 ChatGPT에 제공해 코스피/코스닥별 통계를 분석할 수 있습니다. 인증키는 공유하지 마세요.

## 보호·운영

- 서버 접근 토큰 로그인 필요. 두 API 엔드포인트: `GET /api/recommendations/backtest/status`와 `POST /api/recommendations/backtest/run`.
- POST 예시: `{ "market": "all", "weeks": 4, "cost_bps": 15 }`. 허용 weeks는 **4, 8**뿐입니다. 인증키는 클라이언트로 전달하거나 로그에 출력하지 않습니다.
- 동시에 백테스트와 전체 종목추천 스캔이 실행되지 않도록 제한했습니다. 시작 전에 FSC 키 존재를 확인합니다.
- 공개 서비스에서 공공데이터포털 가격/파생정보 재배포와 상업적 사용 시 데이터 이용조건을 확인하세요. NOVA는 원시 전체 시장 시세 배열을 브라우저 API로 공개하지 않습니다.
- Render 무료 인스턴스는 재시작·절전 시 메모리에 저장된 결과를 잃습니다. 실제 장기 누적 검증용 DB는 후속 개발이 필요합니다.
