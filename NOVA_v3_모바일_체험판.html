장 마감 자료 · 스윙

금융위원회 공공데이터포털의 T+1 일별 주식시세를 우선 활용하고, KRX는 선택적으로 이용합니다. 전체 시장에서 유동성으로 1차 선별하고 최대 8개 종목만 NOVA·OpenDART·별도 기간 검증으로 심층 분석합니다. 현재가·실시간 매수 신호가 아니며 추천이 없을 수도 있습니다.

금융위원회 주식시세 API 키 또는 기존 KRX 인증키 연결 후 시장 검색이 가능합니다.

종목추천 과거 1차 선별 백테스트 · v4.4

4주·8주 과거 주간 기준일을 복원하고 1·3·5·10거래일 후 실제 수익률을 평가하는 기능입니다. 체험판에서는 실제 금융위원회·Yahoo 데이터에 접근하지 않으므로 실행하지 않습니다. v4.4 운영 서버에서 확인하세요.

금융위원회 공공데이터·KRX 연결 기준 확인

권장 경로: 공공데이터포털의 금융위원회_주식시세정보를 활용 신청하고, Render에 FSC_STOCK_API_KEY로 발급된 공공데이터포털 인증키를 입력하세요. KRX 키와 다릅니다. https://www.data.go.kr/data/15094808/openapi.do

금융위원회 시세는 다음 영업일 오후 1시 이후에 업데이트되는 지연 데이터입니다. 과거 봉 기준일 불일치 시 매수 추천을 보류하며, 모든 심층 조건을 통과한 후보가 없으면 결과는 0개입니다. 공공누리 제4유형과 원천 데이터의 재배포 제한을 준수해야 합니다.

KRX OPEN API에서 인증키 발급 및 유가증권 일별매매정보·코스닥 일별매매정보 서비스 이용 승인을 받으세요. Render의 Environment에 이름 KRX_API_KEY로 키를 저장합니다. API 키를 채팅이나 GitHub에 입력하지 마세요.

KRX 선택 시에는 장 마감 후 제공되는 일별 자료 기준이며 실시간 전체 시장 감시가 아닙니다. 오늘 자료가 아직 게시되지 않으면 직전 거래일로 조회합니다. 1차는 거래대금·규모·당일 가격 변동만 검토하고, 최대 8개 후보만 Yahoo 및 OpenDART로 심층 분석합니다.

① 종목 분석 화면에서 종목을 선택하세요. ② 가격 추이의 차트 봉 주기에서 일봉·주봉·월봉·연봉을 변경할 수 있습니다. ③ 캔들을 눌러 해당 봉의 시가·고가·저가·종가·거래량을 확인하세요.

주봉은 월요일 시작, 월봉은 매월 1일 시작, 연봉은 1월 1일 시작으로 묶습니다. 해당 기간이 끝나지 않았다면 마지막 봉은 ‘미완성’으로 표시됩니다. 오래된 상장 종목일수록 연봉 EMA 확인에 유리합니다. KIS는 제공되는 일봉 기간이 짧을 수 있어 장기차트는 Yahoo 공급원이 필요할 수 있습니다.

중요: 차트 봉 주기만 바뀌며 NOVA의 매수·매도·관망 판단은 상단의 1분·5분·일봉 스윙 분석 주기를 유지합니다. 주·월·연봉 자체의 신호나 적중률 검증 기능은 아직 제공하지 않습니다.

NEW종목별 매수 조건 적중률 · v4.0⌄

종목 분석 아래 현재 매수 조건별 과거 성과에서 현재 충족된 기술적 매수 조건을 확인하세요. 훈련 적중률/최근 검증 적중률은 별도로 표시합니다. 표본이 적거나 최근 검증에서 이익이 없다면 조건을 추천하지 않습니다.

하단 과거 검증 → 이 종목의 매수 조건 순위에서 전체 10개 기술 조건을 비교하세요. 과거 첫 70%에서 후보를 뽑고 최근 30%로 확인하며, 거래비용을 반영합니다. 최종 매수 신호, 재무 위험 및 시세 지연 판단은 기존 규칙을 따릅니다.

01종목 검색과 분석 시작⌄

① 상단 검색창에 삼성전자, 에코프로처럼 이름을 입력합니다. 검색 후보에서 시장(KOSPI·KOSDAQ)과 코드를 확인해 선택하세요.

② 1분 단타 · 5분 단타 · 일봉 스윙 중 주기를 선택하고 분석 결과를 확인합니다. 데이터가 지연되거나 휴장 중이면 마지막 완료봉의 시간을 확인하세요.

02기본 신호 vs 안정형 신호⌄

기본 신호는 기존 규칙 기반 13개 역할이 판단한 매수·매도·관망 의견입니다. 투표 수를 상승 확률로 해석하지 마세요.

안정형 신호는 기본 매수 후보에 추세·모멘텀·거래량·과열·위험/비용 5가지 조건을 적용합니다. 핵심 조건을 통과하고 총 5개 중 4개 이상을 만족해야 매수 후보를 유지합니다. 스윙은 재무 위험 필터도 추가로 적용됩니다.

분석 결과의 ‘SIGNAL QUALITY → 안정형 매수 선별’에서 통과/탈락 이유를 확인하세요. 위 비교는 설명용 예시입니다.

03기본·안정형 과거 적중률 비교⌄

① 먼저 종목을 분석합니다. ② 하단 ‘과거 검증’ 탭을 엽니다. ③ ‘기본 vs 엄격 매수 신호’ 카드를 찾습니다.

두 신호의 적중률·표본 수·평균 순변화·선별 비율을 함께 비교하세요. 적중률이 높아도 표본이 적거나 비용을 뺀 수익이 나쁘면 개선이라고 단정할 수 없습니다.

이 비교는 과거 최근 20% 자료에 대한 가상 평가입니다. 미래 적중률이나 수익을 보장하지 않습니다.

04재무·공시와 위험 점수 보기⌄

종목을 분석한 뒤 하단 ‘재무·공시’ 탭을 누릅니다. OpenDART의 매출액, 영업이익, 순이익, 부채비율, 현금흐름 및 원문 공시를 확인할 수 있습니다.

재무 위험 점수는 스윙 신규 매수 후보를 보류하는 보조 필터입니다. 점수 자체가 상승 확률은 아니며 자료 기준일과 연결·별도 재무제표 구분을 확인해야 합니다.

05관심종목 한꺼번에 감시⌄

분석 결과의 ‘☆ 관심’을 눌러 종목을 저장한 뒤 하단 ‘관심 종목’에서 2개 분석 주기를 선택합니다. ‘관심종목 한꺼번에 분석’을 누르면 최대 5개 종목을 비교할 수 있습니다.

15분 자동 조회와 신호 변경 알림은 관심종목 화면이 열려 있을 때만 작동합니다. 앱을 닫은 상태의 24시간 감시 및 푸시는 제공하지 않습니다.

06실제 신호 성과 기록과 백업⌄

종목 분석 이후 하단 ‘과거 검증 → 신호 이후 실제 결과 추적’에서 기록을 확인합니다. 1·3·5·10거래일의 완료 종가가 생긴 후 ‘최신 종가로 평가’를 누르세요.

기록은 이 기기 브라우저에만 저장됩니다. 휴대폰을 바꾸거나 브라우저 데이터를 지우기 전에 ‘JSON 백업’ 파일을 보관하세요. 필요하면 ‘JSON 복원’을 사용합니다.

07캔들차트와 종목뉴스⌄

종목 분석에서 상승/하락 캔들·거래량·EMA20·EMA50을 확인합니다. 두 손가락으로 확대하고 밀어서 이동하거나 우측 확대·축소 버튼을 사용하세요.

하단 종목뉴스에서 선택한 기업의 최신 기사 제목과 출처·시각·원문을 확인합니다. 기사 내용은 신호 계산에 사용하지 않습니다.

08설정 · 로그인 유지 · 앱 설치⌄

우측 상단 ⚙ 설정에서 시세 공급원, 왕복 거래비용, 자동 재조회 등을 설정할 수 있습니다. 개인 기기에서는 ‘30일 로그인 유지’를 켤 수 있습니다.

홈 화면 설치 메뉴가 보이지 않으면 ChatGPT 내부 브라우저가 아닌 갤럭시 Chrome 또는 삼성 인터넷에서 NOVA HTTPS 주소를 열고 메뉴에서 ‘홈 화면에 추가’를 선택하세요.

NOVA는 개인 연구용 분석 도구이며 실시간 체결·실거래 주문을 지원하지 않습니다. 데이터 지연이나 분석 오류가 생길 수 있고, 매수·매도 표시는 투자 수익을 보장하지 않습니다.

NOVA v4.4 · 실거래 주문 없음 · 13개 규칙 기반 역할(독립 AI 13개 아님) · 과거 검증은 미래 수익을 보장하지 않습니다.
